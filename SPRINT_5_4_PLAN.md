# Sprint 5.4 — Persistencia web y branding institucional

## Objetivo

Evolucionar IUS-Razón desde una demostración pública reproducible hacia una
aplicación web con identidad institucional y persistencia permanente mediante
herramientas con plan gratuito.

## Alcance visual

1. Integrar únicamente el logo principal de IUS-Razón.
2. Mostrar el logo centrado al 50 % del ancho disponible.
3. No utilizar el logo gráfico de Sképsis Apps.
4. Conservar como firma textual:
   `Powered by Sképsis Apps · © 2026 Sképsis Apps`.

## Alcance técnico posterior

1. Preparar una conexión gratuita con PostgreSQL administrado.
2. Mantener SQLite para desarrollo local y pruebas.
3. Validar persistencia después de reinicios y redespliegues.
4. Documentar variables de entorno sin publicar secretos.
